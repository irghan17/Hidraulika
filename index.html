📖 Panduan Penggunaan

1
Isi Data Saluran di Tab Input.
Masukkan Q, b, m, n, S₀. Untuk saluran persegi, set m = 0.
2
Isi Data Bangunan Air sesuai skenario yang diinginkan.
Bisa 1 atau lebih skenario sekaligus (pintu, bendung, penyempitan).
3
Klik "Hitung Semua Skenario" atau ubah nilai input (auto-hitung).
Hasil muncul otomatis di Tab Hasil dan Tab Grafik.
4
Baca Tab Kalkulasi & Hasil — ringkasan 4 kedalaman acuan, Es, Fs, Fr, dan jarak profil.
Warna hijau = kondisi normal; merah = terbendung/kritis.
5
Lihat Tab Visualisasi Grafik untuk Kurva E–y dan Profil Muka Air.
Grafik interaktif: hover untuk nilai, klik legenda untuk sembunyikan/tampilkan seri.

📐 Logika Hidraulika

1. Kedalaman Normal (yn) — dihitung dari Manning dengan metode biseksi:
Q = (1/n) · A · R^(2/3) · S₀^(1/2)
Jika yn > yc → saluran landai (aliran normal subkritis).
2. Kedalaman Kritis (yc) — kondisi Froude = 1:
g · A³ / T = Q²
Diselesaikan dengan biseksi pada fungsi f(y) = g·A³/T − Q².
3. Energi Spesifik (Es) & Gaya Spesifik (Fs)
Es = y + Q²/(2g·A²) Fs = Q²/(g·A) + b·y²/2 + m·y³/3
Satu nilai Es punya dua kedalaman (subkritis & superkritis).
4. Pintu Air
y₁ = Cc · a → superkritis di hilir pintu E_hulu = E_hilir = Es(y₁) → cari y_sub (subkritis)
5. Bendung
E₂ = E₁ − Δz Jika E₂ < Emin → TERBENDUNG E_hulu = Emin + Δz, cari y_sub hulu baru y kaki = cabang superkritis pada E_hulu
6. Penyempitan
Hitung yc₂ dan Emin₂ pada lebar b₂ Jika E₁ < Emin₂ → TERBENDUNG E_hulu = Emin₂, cari y_sub pada lebar b
7. Loncatan Hidrolik
Kedalaman konjugat: cari y₂ sehingga Fs(y₂) = Fs(y₁) y₂ > yn → loncatan di hilir bangunan
8. Profil Muka Air — Standard Step
Sf = (n·V / R^(2/3))² ΔX = (E_hilir − E_hulu) / (S₀ − S̄f)
Kurva M1: subkritis y_sub → yn(1+ε), hitung ke hulu.
Kurva M3: superkritis y₁ → y_j, hitung ke hilir.
